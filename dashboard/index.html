🔔 سجل التنبيهات

🔒 مراقبة شهادات TLS

فحص تلقائي يومي لشهادات النطاقات المسجلة — تنبيه مسبق قبل انتهائها عبر كل قنوات التنبيه المفعّلة (ويبهوك، إيميل، تيليجرام، Slack، Teams).

🌐 مراقبة الجهوزية (Uptime)

فحص HTTP دوري للروابط المسجلة — تنبيه فوري عند التوقف (بعد فشلين متتاليين لتفادي الإنذارات الكاذبة) وتنبيه عند عودة الموقع للعمل.

📢 صفحة الحالة العامة وسجل الحوادث

صفحة حالة عامة (مثل صفحات GitHub/Stripe) تعرض جهوزية روابطك وآخر 90 يوماً والحوادث — تُفتح الحوادث تلقائياً عند توقف أي رابط وتُغلق عند عودته.

أهلاً بك في BraimSec 🛡️ — منصة فحص الثغرات الأمنية للمؤسسات. ثلاث خطوات سريعة وتصبح جاهزاً:

🔍
فحص تلقائي معزولsemgrep وgitleaks وفحص التبعيات — كلها تعمل داخل sandbox معزول تماماً عن بقية النظام.
⏰
فحص دوري وتنبيهات فوريةجدولة يومية أو أسبوعية، وتنبيه فوري بالإيميل أو الويبهوك أو تيليجرام عند أي نتيجة جديدة.
📊
تقارير للمديرين وتكاملاتتقارير تنفيذية PDF بالعربية تُرسل تلقائياً، وتصدير SARIF لتكامل GitHub code scanning.
